# 휴지통.exe 복원 소스 — 한국어 주석 전체판

## 먼저 알아둘 중요한 사실
이 자료는 **휴지통.exe의 원래 작성자가 가진 원본 .py가 아니라**, Python 3.10 바이트코드에서 수동 복원한 소스를 기준으로 주석을 단 자료야. 따라서 복원 과정에서 누락되거나 잘못 재구성된 부분이 있을 수 있고, 실제 장치에서 동일하게 실행된다고 보장하지 않아. 단, 이번 작업에서 기존 복원 소스의 **Python 실행 구문은 단 한 줄도 수정하지 않았어.** 주석만 추가했고 각 모듈의 AST(실행 구조) 동일성 검사를 통과했어.

## 폴더 구성
- `source/` : 한국어 설명 주석을 직접 단 Python 4개 파일 (공부할 때 이 폴더 사용)
- `source_original/` : 주석을 추가하기 전의 기존 복원 Python 4개 파일 (비교용)
- `source/main.ui` : 원본에서 추출한 Qt UI 배치
- `assets/` : 원본 리소스
- `bytecode/` : 기존 복원 패키지에 포함된 원본 바이트코드
- `analysis/` : 원본 추출 분석 자료
- `코드_따라읽기_설명서.md` : 실행 순서·문법·중요 함정에 대한 쉬운 설명
- `주석_검증_결과.txt` : 원본과 실행 구조 비교 결과

## 가장 쉬운 읽는 순서
1. `코드_따라읽기_설명서.md`를 먼저 연다.
2. `source/Untitled-1.py`에서 `ExtractWindow`의 `start_extract`와 `id_scan_done`을 읽는다.
3. `source/kait_extract.py`에서 `start_id_scan`과 `kait_onlyidscan`을 읽는다.
4. `source/isc_server.py`에서 `.env`를 읽는 구간을 확인한다.
5. 필요하면 `source/common.py`에서 관리자 권한·파일·Windows 함수들을 본다.

## 실행·보안 관련 주의
- 일부 DLL 경로, 관리자 권한 검사 및 Defender 예외 등록은 기존 복원 소스에 그대로 남아 있어.
- `isc_server.py`에는 실제 네트워크 업로드 함수가 **정의**되어 있어. 함수가 존재한다는 것과 일반 스캔 과정에서 호출되는 것은 별개야.
- `kait_extract.py`에는 스캔 결과 JSON에서 `ID_IMG1`을 가져오는 흐름이 있어. 보호 처리 이전 DIB 자동 저장 기능이 추가된 건 아니야.
- 원본 `.env`·아이콘은 이전 분석에서 파일을 확보하지 못했으며, 이 ZIP이 단독 실행 환경이라는 뜻은 아니야.
- 이 문서는 공부를 위한 주석판이고 DLL 및 기존 EXE를 수정하지 않았어.
